Installer — Ouvrez l'adresse de l'application dans Chrome, menu ⋮ → "Ajouter à l'écran d'accueil" (ou "Installer l'application"). Elle s'ouvre ensuite comme une application, hors connexion compris.
Se repérer — La barre du bas regroupe les écrans en 4 sections : Suivi (Tableau de bord, Transactions, Dépenses récurrentes, Budget, Revenus, Alertes), Planifier (Objectifs, Projection, Suivi annuel), Patrimoine (Patrimoine net, Investissements, Crédit, Multi-Crédits, Maintenance), Outils (Paramètres, Référentiel, Guide). Saisir vite avec le bouton "+" — Il demande d'abord Dépense ou Revenu. Dépense : montant, catégorie (vos 4 plus fréquentes en pastilles), date du jour, mode de paiement ; c'est le même enregistrement que le formulaire de Transactions. Revenu : montant, source, mois ; le montant s'ajoute à la case source / mois de l'onglet Revenus, et la valeur déjà saisie est affichée pour éviter les doublons. Lire les tableaux — Sur téléphone, les tableaux sont présentés en cartes (une ligne = une carte) avec les mêmes boutons. Les grilles mois par mois (Revenus, Crédit, Projection, Suivi annuel) gardent la première colonne fixe : faites défiler vers la droite pour voir les mois.

Verrouiller / Quitter — 🔒 verrouille immédiatement (code PIN). Le bouton marche/arrêt « Quitter » enregistre, synchronise si activé, puis verrouille : fermez ensuite l'application depuis les applications récentes (Android n'autorise pas une application web à se fermer seule).
Pages longues — Dans Paramètres et ce Guide, touchez un titre pour ouvrir sa section.

🔁 Dépenses récurrentes / fixes
À quoi ça sert — Déclarez une seule fois vos charges fixes (loyer, abonnements, assurances, remboursements de crédit...) dans l'onglet 🔁 Dépenses récurrentes : plus besoin de les ressaisir chaque mois.
Génération automatique — À chaque ouverture de l'application, toutes les échéances dues depuis votre dernière visite sont créées automatiquement dans 📝 Transactions — y compris en rattrapage si vous n'avez pas ouvert l'app depuis plusieurs mois. Reconnaître une transaction générée — Les transactions issues d'une dépense récurrente portent la mention "🔁 généré automatiquement" dans leurs notes ; vous pouvez les modifier ou les supprimer comme n'importe quelle transaction, sans affecter la récurrence elle-même.

💾 Sauvegarde, synchronisation et multi-appareils
Où sont mes données ? — Enregistrées automatiquement sur cet appareil (téléphone ou PC) à chaque saisie. Rien ne quitte l'appareil tant que la synchronisation n'est pas activée.
☁️ Synchronisation entre appareils — Dans ⚙️ Paramètres › Synchronisation : créez un compte (e-mail + mot de passe) et une phrase secrète. Les données sont chiffrées sur l'appareil avec cette phrase avant l'envoi : sans elle, personne ne peut les lire. Connectez chaque appareil (PC, téléphone, web) avec le même compte et la même phrase ; la synchronisation se fait à l'ouverture, après chaque saisie et avec le bouton Quitter.
